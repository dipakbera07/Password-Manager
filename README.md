# Password Manager 🔐

A simple **password manager application** built with React, designed to store and manage passwords through a clean and user-friendly interface.

### 🛠️ Tech Stack

* React
* JavaScript
* Vite
* CSS

### ✨ Features

* Add and manage passwords
* Simple and responsive UI
* Easy-to-use interface
